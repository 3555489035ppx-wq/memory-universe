# Memory Universe Design Decisions

## 1. Space is a navigation model

The universe is organized around proximity, grouping, and movement. 3D is used only where those relationships add meaning beyond a thumbnail grid.

## 2. Music is part of the story timeline

Music provides continuity and emotional pacing. The camera, photo movement, and chapter transitions respond to the same timeline rather than treating audio as a separate player widget.

## 3. Local-first before cloud features

The first product promise is safe exploration of personal memories. Browser-local storage, export, and recovery are therefore part of the core experience, not an afterthought.

## 4. AI proposes; the user owns the memory

Future AI can suggest labels, relationships, summaries, and pacing. It cannot silently rewrite the original photos or metadata. Suggestions remain separate, reviewable, and reversible.

## 5. Coming Soon is a real state

Only the high-school template is complete. Love, breakup, university, work, and custom themes are labeled as in development so the repository does not use empty pages to imply product completeness.
